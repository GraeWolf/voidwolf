# themes/

Shipped TOML presets for `voidwolf-theme` (PR8).

| name | display |
|------|---------|
| voidwolf-dark | Voidwolf Dark (default) |
| gruvbox | Gruvbox |
| catppuccin-mocha | Catppuccin Mocha |
| nord | Nord |
| rose-pine | Rosé Pine |

```bash
voidwolf-theme list
voidwolf-theme set voidwolf-dark
voidwolf-theme validate themes/nord.toml
```
