# Keybindings

Omarchy-inspired Super/Mod4 map for voidwolf (dwm).

> **Status:** Stub for PR1. Full mapping and `config.h` land in **PR6 / PR6b**.  
> Source of truth until then: [design.md](design.md) (Keybindings section).

## Locked focus / Super+K policy

| Bind | Action |
|------|--------|
| Super+H / Super+L / Super+J | focusdir left / right / down |
| Super+Arrows | focusdir in that direction |
| Super+K | keybind cheatsheet only (not focus) |
| Super+Shift+L | layout cycle |
| Super+Shift+H/J (+ arrows) | movestack / swap |

## Core binds (preview)

| Bind | Action |
|------|--------|
| Super+Return | Terminal (st) |
| Super+Shift+Return | Browser (brave-origin) |
| Super+Space | Launcher (dmenu wrapper) |
| Super+Alt+Space | voidwolf control menu |
| Super+Escape | System menu |
| Super+Ctrl+L | Lock |
| Super+W | Close window |
| Super+T | Toggle floating |
| Super+F | Fullscreen |
| Super+1–9 | Tags |
| Super+Shift+1–9 | Move client to tag |
| Super+Ctrl+Shift+Space | Theme picker |
| Super+Ctrl+Space | Wallpaper picker |

## Unsupported Omarchy binds

Documented in design Appendix C and the mapping table (e.g. Super+C/V universal clipboard, Hyprland groups).
